**Project Overview**

This project analyzes global COVID-19 data using MySQL to explore trends in cases, deaths, testing, and vaccinations over time. The goal is to transform raw public datasets into structured, queryable insights through data cleaning, type normalization, and analytical SQL queries. By combining case/death data with vaccination/testing data and calculating key metrics, the analysis highlights global patterns, country-level differences, and changes over time.

This repository is organized as a reproducible SQL workflow: initial data quality checks, exploratory queries, KPI calculations, time-series trends, country rankings, vaccination progress analysis, and reusable views. The focus is on core data analyst skills including data preparation, aggregation, ranking, joins, and time-based analysis.
